# Handwritten Digit Recognition using Deep Learning

This is a beginner-level Deep Learning project that classifies handwritten digits (0–9) using a Convolutional Neural Network (CNN) built with TensorFlow/Keras on the MNIST dataset.

## 📌 Project Overview
- **Framework:** TensorFlow / Keras
- **Architecture:** Convolutional Neural Network (CNN)
- **Dataset:** MNIST
- **Optimizer:** Adam
- **Target Accuracy:** ~98%+
